Employee Management System

A full-stack web application for managing employee records with CRUD (Create, Read, Update, Delete) functionality.

Built using React.js, Spring Boot, Spring Data JPA, and MySQL.

📌 Project Overview

The Employee Management System is designed to simplify employee information management. It provides an easy-to-use interface to create, view, update, and delete employee records.

The application follows a client-server architecture, where React handles the frontend, Spring Boot provides RESTful APIs, and MySQL stores employee information.

✨ Key Features

Add Employee: Register new employees with their personal details.

View Employees: Display all employee records in a structured table.

Update Employee: Edit existing employee information.

Delete Employee: Remove employee records from the database.

Form Validation: Validate required fields before submission.

REST API Integration: Communicate between frontend and backend using Axios.

Responsive UI: User-friendly interface built with Bootstrap.
